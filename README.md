# 한 줄 마당

60대 중후반부터 휴대폰으로 큰 칸에서 한 줄을 채우는 8×8 광고 없는 블록 퍼즐입니다. 게임 시작 파일은 저장소 최상위의 `index.html`입니다. 설치나 빌드 없이 정적 파일로 동작합니다.

## GitHub Pages 배포

1. 게임 파일과 `icons/` 폴더를 저장소 최상위에 두고 `main` 브랜치에 푸시합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 고릅니다.
3. **main**과 **/ (root)**를 선택하고 저장합니다. 배포가 끝나면 Pages에 표시된 HTTPS 주소를 휴대폰으로 엽니다.

[GitHub Pages 배포 폴더 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 휴대폰에 앱 설치

게임 화면의 **앱 설치**를 누릅니다. Android Chrome에서는 설치 창에서 확인하고, iPhone에서는 Safari의 **공유 → 홈 화면에 추가 → 추가**를 선택합니다. 설치 후 홈 화면의 **한 줄 마당** 아이콘으로 게임을 엽니다.

## 8×8로 놀이하기

- 조각을 누른 뒤 빈칸을 누르거나, 조각을 판으로 끌어 점선 위치에 놓습니다. 처음에는 가로 두 칸 조각을 아래에서 둘째 줄의 오른쪽 두 빈칸에 놓으면 한 줄이 완성됩니다.
- 판과 점수는 같은 브라우저에서 이어집니다. **쉬기**에서 오프라인 준비 완료를 확인한 뒤 같은 주소를 다시 열면 연결 없이 이용할 수 있습니다.

## 사진으로 조각 꾸미기

1. **사진 꾸미기 → 사진 담기**에서 사진을 고릅니다. 세 장을 한 번에 골라도 여덟 가지 모양에 번갈아 배정됩니다. 한 장부터 사용할 수 있고 최대 여덟 장을 보관합니다.
2. 사진을 누른 뒤 미리보기 안에서 사진을 끌어 얼굴을 가운데에 놓습니다. 키보드에서는 미리보기에 초점을 두고 방향키로 옮깁니다. 크기 조절 막대로 확대하고 **이 모습으로 저장**을 누릅니다. **모양별 사진 고르기**에서는 한 칸짜리를 포함해 각 모양의 사진을 직접 지정할 수 있습니다.
3. 한 조각에는 얼굴이 한 칸에만 보입니다. 줄이 완성되면 지워진 칸에 걸친 각 조각의 사진이 그 자리에서 튀어 오릅니다. 일부만 남은 조각에도 얼굴 하나가 남습니다. 기기의 동작 줄이기를 켜면 사진과 문구를 정지 상태로 잠깐 표시합니다.

고른 사진은 브라우저에서 축소해 이 게임 주소의 로컬 저장 공간에 보관합니다. 서버로 전송하지 않습니다. 사진 기능을 추가하기 전에 저장한 판의 기존 칸에는 조각 모양 정보가 없어 색 블록으로 이어지며, 새로 놓는 조각부터 사진이 표시됩니다.

손주팡의 사진 꾸미기, 큰 사진 칭찬 연출과 따뜻한 색감을 참고했습니다. 이 게임의 프레임과 꽃잎 파티클은 CSS로 그립니다. [참고 프로젝트](https://github.com/novqst47a-ux/grandchild_pang)

## 10×10을 다시 제공할 때

`game.js`의 `playableSizes`를 `[8]`에서 `[8,10]`으로 바꾸면 판 선택 버튼이 나타납니다. 새 이용자는 8×8에서 시작하며 두 크기의 판과 점수는 개별 저장됩니다. 이전 비교판에서 보관한 10×10 진행 상태도 다시 열 수 있습니다. 배포할 때는 서비스 워커의 캐시 버전도 올립니다.

## 로컬 실행

저장소 루트에서 아래 명령을 실행하고 브라우저로 `http://127.0.0.1:8000/`을 엽니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

배포 파일을 업데이트할 때는 `sw.js`의 캐시 버전도 올립니다. 실행 중인 탭을 모두 닫았다가 열면 새 서비스 워커가 적용됩니다.
